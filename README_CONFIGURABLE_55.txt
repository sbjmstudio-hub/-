WIRZA v3 - Configurable 55 Module Edition

What changed:
- All 55 remaining modules now have independent option schemas.
- Every module can be ON/OFF independently.
- HUD modules have per-module:
  position, scale, text size, opacity, corner radius,
  text color, background color, accent color and background ON/OFF.
- Visual and utility modules have their own settings appropriate to the feature.
- Settings persist in %APPDATA%\WIRZA Client\modules.ini.
- Profile Save/Load includes module settings.
- Zoom now uses user-configurable target FOV in degrees.
- Hold C + mouse wheel changes Zoom FOV.
- Normal FOV and Zoom FOV are separate settings.

Important:
This source is NOT claimed to be a fully tested Windows binary yet.
The environment used to create this source cannot compile/test Minecraft for Windows.
Game-data-dependent modules still need verified per-version Bedrock signatures/hooks.
WIRZA keeps unsupported paths disabled rather than guessing memory addresses.

No GitHub workflow is included yet, per the development plan.
