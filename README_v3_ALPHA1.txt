WIRZA Client v3.0 Alpha 1

This is the first real implementation stage toward the requested 55 independent modules.

IMPORTANT:
- All 55 modules are registered independently.
- This build does NOT pretend all 55 are complete.
- The status matrix is MODULE_STATUS_93.md.
- GitHub workflow is intentionally NOT included yet. The plan is to finish the module work first,
  then create a fresh GitHub repository and Windows build workflow.

New in Alpha 1:
- Profile system
- Crosshair module
- Expanded Keystrokes
- OBS diagnostics
- Minecraft version diagnostics
- Fixed psapi link for Memory Usage

Existing real functionality carried forward:
- D3D12 in-game HUD
- FPS
- CPS
- Keystrokes
- Clock
- Playtime
- Memory Usage
- Stopwatch
- native FOV Zoom
- Right Shift menu
- HUD editor foundation
- WIRZA logo

Safety / multiplayer:
- No KillAura, reach increase, fly, speed hack, anti-cheat bypass, ban evasion, or packet tampering.
- Some client visuals may still be restricted by individual server rules.
