WIRZA Client v3 Module Foundation
=================================

IMPORTANT:
This source registers all 55 requested Lunar-inspired features as independent modules.
It does NOT falsely claim that all 55 Bedrock implementations are complete.

What is real in this package now:
- 93 independent module records
- Per-module ON/OFF storage
- Per-module implementation status
- Per-HUD position/scale/opacity/background settings foundation
- Module search/menu foundation
- settings saved to %APPDATA%\WIRZA Client\modules.ini
- Existing FPS, CPS, Keystrokes, Stopwatch, native Zoom carried forward
- Added Clock HUD
- Added Playtime HUD
- Added Memory Usage HUD

The remaining modules must be implemented one-by-one against Bedrock Edition.
Java-only features such as Hypixel/Skyblock/WorldEdit/Fabric/Forge/Sodium are NOT treated as directly portable.
